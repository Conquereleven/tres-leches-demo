# Tagalog review checklist · TL-OMS-01

**Status: NOT reviewed by a native speaker.** These 105 labels were written by the implementer to match the style of the existing `tl.json`. No native or professional review has been performed. English is the fallback and the default; Tagalog is a per-user preference in Operations only and never reaches customers.

How to review: switch Dashboard language to Tagalog, open Orders and one order of each kind (paid delivery, pickup, awaiting payment, cancelled, draft), and tick each row. Corrections go in `src/commerce/locales/tl.json` only; keys and `{{placeholders}}` must not change (a unit test enforces both).
